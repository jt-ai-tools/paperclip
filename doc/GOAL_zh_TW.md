# Paperclip

**Paperclip 是自主經濟的骨幹。** 我們正在打造自主 AI 公司運行的基礎設施。我們的目標是讓由 Paperclip 驅動的公司，集體產出的經濟產值能與全球最大國家的 GDP 相抗衡。我們的每一個決策都應為此服務：使自主公司更具能力、更易治理、更具擴展性且更具真實性。

## 願景 (The Vision)

自主公司 —— 具備真實結構、治理和問責制度的 AI 勞動力 —— 將成為全球經濟的主要力量。不只是一間公司，而是成千上萬、甚至數百萬間。這是一個運行在 AI 勞動力之上，透過 Paperclip 進行協調的完整經濟層。

Paperclip 本身不是公司。Paperclip 是使這些公司成為可能的關鍵。我們是控制平面、神經系統和運作層。每間自主公司都需要結構、任務管理、成本控制、目標對齊和人類治理。這就是我們。我們對自主公司的意義，就像企業作業系統對人類公司的意義一樣 —— 只不過這一次，作業系統是真實的軟體，而非比喻。

衡量我們成功的標準不在於一間公司是否運作，而在於 Paperclip 是否成為建構自主公司的預設基礎 —— 以及這些公司集體是否成為一支能與國家產出相媲美的嚴肅經濟力量。

## 問題 (The Problem)

任務管理軟體做得還不夠。當您的整個勞動力都是 AI 代理時，您需要的不僅僅是一個待辦事項清單 —— 您需要的是整間公司的 **控制平面 (Control Plane)**。

## 這是什麼 (What This Is)

Paperclip 是 AI 代理公司的指揮、通訊和控制平面。它是您進行以下操作的唯一場所：

- **像管理員工一樣管理代理** —— 聘僱、組織並追蹤誰在做什麼
- **定義組織結構** —— 代理自身在其中運作的組織架構圖
- **即時追蹤工作** —— 隨時查看每位代理正在處理的事項
- **控制成本** —— 每個代理的 Token 薪資預算、支出追蹤、消耗率 (Burn rate)
- **與目標對齊** —— 代理能看到他們的工作如何為更大的使命服務
- **儲存公司知識** —— 組織共享的大腦

## 架構 (Architecture)

分為兩個層次：

### 1. 控制平面 (Control Plane，即本軟體)

中樞神經系統。管理：

- 代理註冊與組織架構圖
- 任務分配與狀態
- 預算與 Token 支出追蹤
- 公司知識庫
- 目標階層 (公司 → 團隊 → 代理 → 任務)
- 心跳監控 —— 了解代理何時活躍、閒置或卡住

### 2. 執行服務 (Execution Services，即適配器)

代理在外部運行並向控制平面回報。代理只是被啟動並執行工作的 Python 程式碼。適配器 (Adapters) 連接不同的執行環境：

- **OpenClaw** —— 初始適配器目標
- **心跳迴圈 (Heartbeat loop)** —— 簡單的自定義 Python 程式，進行迴圈、簽到並執行工作
- **其他** —— 任何可以呼叫 API 的運行環境

控制平面不直接運行代理，而是編排它們。代理在各自的環境運行並向總部回報。

## 核心原則 (Core Principle)

您應該能夠透過查看 Paperclip，一眼看透您的整間公司 —— 誰在做什麼、花費多少，以及是否運作正常。
